第 17 讲 17-1.html stringify / parse

JSON 是"数据的文本形式"，对象是"内存里的结构"。两者长得像，但完全不是一回事： 对象可以有函数、可以有 undefined，JSON 不行；JSON 的键必须用双引号，对象的键可以不加。

二、对象转字符串时会被丢掉的东西

这些"丢失"是 JSON 规范的正常行为，不是 bug。

点按钮看结果。
写法方向失败时
JSON.stringify(obj)对象 → 字符串循环引用会抛 TypeError
JSON.stringify(obj, null, 2)对象 → 带缩进的字符串第三个参数控制缩进空格数
JSON.parse(str)字符串 → 对象格式不合法会抛 SyntaxError
所以 parse 一定要包 try / catch。 接口返回的数据不可信，直接用 JSON.parse(res) 而不做异常处理， 线上只要有一次返回了 HTML 错误页（比如 502 页面），整个页面就会白屏。 正确姿势是 try { data = JSON.parse(text) } catch (e) { 提示加载失败 }。

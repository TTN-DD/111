两种定时器

第 17 讲 17-5.html setTimeout / setInterval

setTimeout 只执行一次，setInterval 每隔一段时间执行一次。 两个都能取消，取消的方式不一样：前者靠 clearTimeout 提前拦住， 后者靠 clearInterval 停下。左边那个 3 秒倒计时，在归零前点"取消"就再也不会触发。

用 setTimeout 模拟 setInterval

      
差别的本质：setInterval 不管上一次跑完没有，到点就发；递归 setTimeout 是"跑完再等下一次"。


// 写法一：setInterval —— 固定间隔，可能堆积
const id = setInterval(tick, 1000);
clearInterval(id);

// 写法二：递归 setTimeout —— 上一次结束后才排下一次
function loop() {
  tick();
  timer = setTimeout(loop, 1000);   // 注意用 setTimeout，不是 setInterval
}
loop();

      

        如果 tick 里有耗时操作（比如请求接口），setInterval 会把任务排成一队，
        页面看起来"越跑越乱"；递归 setTimeout 永远等上一次结束，不会堆积。
        所以轮询接口、做动画循环时，优先用后者。

      一定要清的两个场景：① 组件/页面被移除时不清定时器，会继续改已经不存在的 DOM，报一堆错；
      ② 标签页切到后台时浏览器会把间隔拉长到 1 秒以上（省电），所以不能用定时器计数来"精确计时"，
      要算时间差请用 Date.now()。

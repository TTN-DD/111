上面那条是问答主链路，下面那条是知识库的准备流程，虚线表示"答不出来转人工"。 这张图是手写 SVG 的：文字可以被选中、被搜索，导出后放到文档里放大 10 倍也不糊。

悬停任一模块会高亮

为什么这张图不用 Canvas 画

需求SVGCanvas
文字可选中 / 可搜索天然支持不支持（是像素）
放大不失真矢量，无损放大就糊
用 CSS 做悬停高亮rect:hover 一行要自己写命中检测
上千个元素动起来节点多了会卡快得多
导出图片需要转一次toDataURL 直接出
导出 PNG 的原理：把 SVG 序列化成字符串 → 塞进 Blob 生成 blob: 地址 → 用 new Image() 加载 → 画到加倍的 canvas 上 → toDataURL。 注意：如果 SVG 里引用了外部字体或图片，导出时会丢失（跨域限制），所以图里的文字都用了系统字体。

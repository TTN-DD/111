Flex 布局进阶：四组实战结构

第 8 讲 8.html Flexbox 应用

上一页练的是单个属性，这一页练组合：等宽分栏、侧栏固定、圣杯布局、等高列、垂直居中。 这些都是页面里真正会反复出现的结构，写熟了就不需要到处用固定宽度。

一、三个等宽长方框带文字

每个框都是 flex: 1，宽度自动均分；文字长短不同也不影响对齐。

STEP 01

拆结构

先把效果图拆成区块，写出不带样式的 HTML 骨架。

STEP 02

定栅格

用 Flex 或 Grid 把区块摆到位置，这一阶段不加任何装饰。

STEP 03

调细节

最后才调字号、行高、圆角和间距，改一处不影响其他区块。

.three { display: flex; gap: 12px; }
.rect  { flex: 1; min-width: 0; }

min-width: 0 别省：Flex 子项默认最小宽度不小于内容宽度，里面文字一长就会把分栏挤变形。

二、侧栏固定宽度 + 内容自适应

flex: 0 0 168px 表示不放大、不缩小、固定 168px。

三、圣杯布局

外层是纵向 Flex（头 / 中间 / 尾），中间那层再横向 Flex 分成三栏。

header — 顶部通栏
nav
固定 118px

主内容区

三层 Flex 嵌套：最外层 flex-direction: column， 保证页脚始终贴底；中间层横向排列，主内容 flex: 1 吃掉剩余宽度。 这样无论内容多少，页脚都不会浮在页面中间。

四、等高列与垂直居中

左边三列文字长短不同，高度自动拉齐；右边是 Flex 做居中的标准写法。

短

只有一行。

中

内容长一些，占三行左右。注意三列的高度是完全一致的，因为 align-items 默认就是 stretch。

长

这一列写得最长，用来验证另外两列会不会跟着一起变高。答案是会——这就是 Flex 相比浮动布局最省心的地方，浮动还得自己补 min-height。
align-items + justify-content = 完美居中 
.center-stage {
  display: flex;
  align-items: center;      /* 交叉轴居中 */
  justify-content: center;  /* 主轴居中 */
}
组合规律：横向排列用 display:flex，纵向排列就加 flex-direction: column，需要某一项吃掉剩余空间就给它 flex: 1; min-width: 0;。 这三句话能解决课上遇到的大部分布局题，剩下的才需要 Grid。

选择器综合练习

第 4 讲 4.html CSS 选择器

七组选择器，每组都能看到代码和它命中的元素。练到后面你会发现： 能用结构选择器解决的问题，就不该回到 HTML 里加一堆类名。

一、后代 vs 子代

左边是 .tree li（所有后代），右边是 .tree > ul > li（只有直接子元素）。

  • 第一层：被两条规则都选中
  • 第一层：同上
    • 第二层：只被后代选择器选中
    • 第二层：同上
.tree li          /* 后代，全部命中 */
.tree > ul > li   /* 子代，只管第一层 */
左竖线 = 子代选择器加的边框 第二层没有竖线

二、相邻兄弟选择器

h4 + p 只命中紧跟在 h4 后面的第一个 p。

小标题

紧跟在小标题后面的段落，被 + 命中，显示为绿色。

第二个段落，不在 h4 的相邻位置，保持灰色。

三、属性选择器

按 href 的开头、结尾匹配，自动加后缀和前缀标记。

https 外链 站内链接 课程讲义 
a[href^="https://"]  /* 以 https:// 开头 */
a[href$=".pdf"]      /* 以 .pdf 结尾 */

四、结构伪类

不用加任何类名，靠位置就能做斑马纹和首尾样式。

  • 第一行（:first-child 加粗）
  • 第二行
  • 第三行（:nth-child(odd) 底色）
  • 第四行
  • 第五行（:nth-child(odd) 底色）
  • 最后一行（:last-child 去掉下边框）

五、:not() 排除

给所有按钮一个样式，唯独排除带 danger 类的那个。

button:not(.danger) { /* 除了 .danger 都命中 */ }

六、伪元素

::before / ::after 创造的是"假元素"，不占 DOM，常用来做装饰和图标。

能用 CSS 画出来的装饰，就不要多写一个标签。伪元素是最省结构成本的做法。

写法名称权重
div p后代0,0,2
div > p子代0,0,2
h4 + p相邻兄弟0,0,2
h4 ~ p通用兄弟0,0,2
a[href$=".pdf"]属性0,1,1
li:nth-child(odd)伪类0,1,1
::before伪元素同标签
练习体会：选择器越短越好。像 div.wrap > ul > li > a.link 这种层层写死的选择器， 结构一变就全废；换成单个类名反而更稳，也不影响优先级判断。

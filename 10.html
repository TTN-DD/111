过渡与动画

第 10 讲 10.html transition / transform / @keyframes

过渡（transition）需要触发条件，比如鼠标悬停，两个状态之间自动补帧； 动画（animation）自己就能跑，用 @keyframes 定义多个关键帧。 两者都只改 transform 和 opacity 时最流畅，因为它们走 GPU 合成，不触发重排。

一、transition：四个属性

把鼠标移到卡片上 hover 看过渡效果。

背景与文字transition: background .25s ease
边框颜色三个属性同时过渡，用逗号分隔
只影响自己不给 transition 就是瞬间跳变
transition: 属性 时长 缓动 延迟;
/* 例：background .25s ease 0s */
transition: background .25s ease, color .25s ease;

二、transform：位移、缩放、旋转

四个方块都只有 hover 时才变，过渡负责把它变得顺滑。

translateY(-8px)
scale(1.12)
rotate(6deg)
组合 + 阴影

第二个用了 cubic-bezier(.34, 1.56, .64, 1)，第三个参数超过 1， 会产生轻微"弹一下"的效果——比默认的 ease 更有手感，但别用在需要精确对齐的地方。

三、缓动曲线对比

鼠标移进任意一行，五个圆点同时出发、同一时长，只有曲线不同。

linear
ease（默认）
ease-in
ease-out
cubic-bezier 回弹

进场动画常用 ease-out（快进慢停），退场用 ease-in； 匀速的 linear 只适合旋转、进度这类需要等速的东西。

四、@keyframes：不用触发的动画

这些动画页面一打开就在跑，靠 animation: 名称 时长 缓动 循环次数 启动。

加载环

格式错误
错误抖动
shake .6s infinite 
@keyframes spin {
  to { transform: rotate(360deg); }
}
.loader {
  animation: spin .9s linear infinite;
}
两条实践建议： ① 动画只改 transform 和 opacity。改 width / top / margin 会让浏览器每一帧重新计算布局，机器差一点就掉帧； ② 加上 @media (prefers-reduced-motion: reduce) 关掉动画—— 有些用户会因为前庭功能问题对运动敏感，这个媒体查询在系统设置里能关掉全部动画。 本页已经加上了，你可以在系统设置里打开"减少动态效果"验证。

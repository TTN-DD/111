表单示例：课程报名

第 3 讲 3.html HTML 表单 + CSS

这一页把常用表单控件全部放进来，重点是三件事：label 与控件的关联、 input 的 type 要选对（手机键盘、日期选择器、邮箱校验都靠它）、 name 属性决定提交时的字段名。页面没有接后端，提交到 # 只为演示。

报名表

带 * 的是必填项，用 HTML 自带的 required 校验。

基本信息

type="email" 会在提交时自动校验格式，不需要写 JavaScript。

课程选择
年级 *

name 相同的单选框互为互斥关系，只能选一个。

想学的方向

复选框可以多选，提交时同名字段会出现多个值。

补充材料

accept="image/*" 让文件选择器默认只显示图片。

自评基础水平
1 – 10
控件标签要点
单行文本input type="text"配 placeholder 给示例，不要用 placeholder 代替 label
密码input type="password"只是遮住显示，不加密，传输要靠 HTTPS
单选 / 复选input type="radio|checkbox"同名 radio 互斥，checkbox 可多选
下拉select + option选项多时比单选框省空间
多行文本textarea内容写在标签之间，不在 value 里
容易漏的一点： <label for="xxx"> 里的 for 必须等于控件的 id。 写上之后点文字就能聚焦输入框，读屏软件也会把标签念出来—— 这是表单可访问性最基础的一条，成本极低但经常被忘。

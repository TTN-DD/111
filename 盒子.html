盒子模型：四层结构与 box-sizing

第 4 讲 盒子.html CSS 盒模型

页面上每一个元素都是一个矩形盒子，从里到外四层： content（内容）→ padding（内边距）→ border（边框）→ margin（外边距）。 搞不清这四层，就会出现"我明明设了 width:200px，为什么占了 248px"这种问题。

二、box-sizing：那个 48px 是怎么多出来的

两个盒子都写了 width:200px、padding:20px、border:4px，实际占据的宽度不一样。

content-box（默认）

box-sizing: content-box

200px 只是内容区
实际占据：200 + 20×2 + 4×2 = 248px

border-box（推荐）

box-sizing: border-box

200px 含内边距和边框
实际占据：200px

左边那个盒子明显更宽，因为默认的 content-box 把 padding 和 border 加在了 200px 之外。所以实际项目里几乎都会在开头统一写上： 

*, *::before, *::after {
  box-sizing: border-box;   /* 让 width 就是最终宽 */
}

三、margin 的两种特殊情况

这两个坑几乎每个初学者都会踩一次。

现象说明处理
外边距折叠 上下相邻两个块级元素的 margin 不会相加，而是取较大值。两个 20px 之间只有 20px，不是 40px。 改用单方向 margin（统一用 margin-bottom）
父元素高度塌陷 子元素全用 float 时脱离文档流，父元素高度变成 0。 父元素加 overflow: hidden 或用 Flex
记住一条就够了： margin 是盒子外面的空白，属于"我和别人之间的距离"； padding 是盒子里面的空白，属于"我的内容和我的边框之间的距离"。 点背景色能不能盖住它，一眼就能分清：能盖住的是 padding，盖不住的是 margin。

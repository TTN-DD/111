极坐标玫瑰线

第 18 讲 18-4.html Canvas 极坐标 + 参数方程

公式只有一行：r = R · cos(kθ)。把 θ 从 0 扫到 2π，每算一个半径就画一个点， 连起来就是一朵玫瑰花。k 为奇数得 k 瓣，k 为偶数得 2k 瓣——拖动滑块能直接看到这个规律。

参数

极坐标 → 直角坐标

Canvas 只认 x / y，所以每一步都要转一次。

for (let i = 0; i <= steps; i++) {
  const t = (i / steps) * Math.PI * 2;   // θ 从 0 扫到 2π
  const r = R * Math.cos(k * t);         // 玫瑰线方程
  const x = cx + r * Math.cos(t + rot);  // 转成直角坐标
  const y = cy - r * Math.sin(t + rot);  // 减号：canvas 的 y 轴朝下
  i ? ctx.lineTo(x, y) : ctx.moveTo(x, y);
}

y 用减号是新手最容易错的一行：数学里 y 轴朝上，canvas 里 y 轴朝下，不取反整个图形会上下翻转。

现象原因
k 为奇数 → k 瓣cos 在 [0, π] 区间走完一圈花瓣，π 到 2π 时 r 变负，画到反向重叠
k 为偶数 → 2k 瓣正负半周不重叠，各画 k 瓣
曲线边缘有锯齿采样点太少；把 steps 提到 720 以上就顺了
看起来不圆canvas 宽高不等比，或没有按 devicePixelRatio 缩放
为什么不用 ECharts：玫瑰图是 ECharts 的 polar + bar 组合，但要引 1MB 的库。 这朵线只需要一个 for 循环和 20 行绘制代码——能自己画的图就别引库， 尤其当项目只用到这一个图表的时候。

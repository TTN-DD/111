Promise 包饺子

第 17 讲 17-6.html 串行 / 并行 / 报错

包饺子的顺序是有讲究的：和面和和馅可以同时进行（Promise.all）， 但"包"必须等这两样都好了，煮又必须等包完。 勾掉"并行"再看一遍，总耗时立刻从 4.6 秒变成 6.1 秒——这就是有依赖关系的任务该串行、没依赖的该并行。

厨房进度 总耗时：-- 0.0s

当前：和面 与 和馅 并行 —— 两件事互不依赖，可以同时开火。 

点「开始包饺子」看 Promise 的执行顺序。

代码长什么样

// 每一步都是一个返回 Promise 的函数
const buyFlour  = () => wait("买面粉", 900);
const knead     = () => wait("和面",   1600);
const mixFilling= () => wait("和馅",   1400);
const wrap      = () => wait("包饺子", 2200);
const boil      = () => wait("下锅煮", 1200);

async function cook() {
  await buyFlour();                       // 必须先买
  await Promise.all([knead(), mixFilling()]);  // 这两件并行
  await wrap();                           // 等两样都好了才包
  await boil();
}

// wait 内部就是一个 Promise
function wait(name, ms) {
  return new Promise(resolve =>
    setTimeout(() => { log(name + " 完成"); resolve(name); }, ms)
  );
}
写法耗时适用
全部串行 await900 + 1600 + 1400 + 2200 + 1200 = 7.3s每一步都依赖上一步
和面/和馅并行（本页）4.6s（省 1.4s，等于较短的那个任务）任务之间无依赖
全部并行2.2s，但饺子会煮成一锅糊只在真的没有先后要求时可用
失败怎么处理：点"演示失败"看看——buyFlour 抛出错误后， 整个 async 函数会立刻跳到 catch，后面三步一步都不会执行。 这就是 await 链式调用的特性：中途任何一步 reject，剩下的全部短路。 如果某一步失败可以容忍（比如"和馅"失败改用现成肉馅），要单独 try/catch 那一小段。

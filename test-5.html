影视排行

课堂测试 4 test-5.html 双列前十 + 时间维度切换

榜单类页面的标准结构：上方筛选、下方两列、每行固定四段（序号 / 海报 / 片名信息 / 分数）。 两列用 Grid 均分，行内再用 Grid —— 嵌套 Grid 比一堆 float 好维护得多。

海报为占位色块：真实项目里应给 <img> 设置固定宽高比，避免图片加载完成后把列表撑开。

要点做法
两列高度不齐不追求两列等高，只保证每行高度固定（align-items: center）
片名过长单行截断 + title 属性，鼠标悬停能看全名
分数不换行white-space: nowrap，并用等宽字体让小数点对齐
切换维度只替换数据数组，DOM 结构不变，避免写三套 HTML
前十名分成两列数据按 5 条一组渲染到两列，读起来符合"竖着读"的习惯
为什么竖着分而不是横着分：横着排（第 1–5 名一行、第 6–10 名一行）会让视线左右跳， 竖着排（左列 1–5、右列 6–10）视线只往下走，扫读更快。这是排版习惯问题，不是技术问题。

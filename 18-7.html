CSS 3D 柱状图

第 18 讲 18-7.html 轴测投影 · 不引 Three.js

每根柱子由三个面拼成：正面是矩形，顶面是把矩形 skewX(-45°) 压出的平行四边形， 侧面用 skewY(-45°)。三个面共用一个"厚度"变量，拖动滑块就能改变柱体的厚度， 看上去就像换了个观察角度。

悬停柱子看数值

三个面怎么拼的

关键只有一个：--depth 这一个变量，三个面同时引用它。

.bar { --depth: 14px; position: relative; }

/* 正面：普通矩形 */
.bar .front { inset: 0; background: #2f6fed; }

/* 顶面：压扁成平行四边形，原点设在左下角 */
.bar .top {
  top: calc(-1 * var(--depth)); height: var(--depth);
  transform: skewX(-45deg); transform-origin: left bottom;
}

/* 侧面：同理，原点设在左上角 */
.bar .side {
  right: calc(-1 * var(--depth)); width: var(--depth);
  transform: skewY(-45deg); transform-origin: left top;
}

transform-origin 是这三个面的命门。顶面锚在左下角、侧面锚在左上角， 倾斜之后才能严丝合缝地贴住正面。锚点写错一个，柱子的角就会裂开一道缝。

做法体积能改样式吗适合
CSS 轴测投影（本页）0 KB完全可控固定视角的静态图表
Three.js约 600 KB要写 WebGL 代码需要真实光照、自由旋转
ECharts GL约 1 MB受配置项限制大屏里成套的 3D 图表
预渲染图片几十 KB不能改数据不变的一次性配图
别被"3D"骗了：这里其实不是真 3D——它没有透视、没有光照、转不了视角。 它叫轴测投影（平行投影），只是"看起来有厚度"。 对于一张静态柱状图，这已经足够了，而且比 WebGL 轻一千倍。 真正需要"鼠标拖着转"的场景，才值得上 Three.js。

四标签排行榜

课堂测试 0 test-1.html 标签切换 + 列表排版

新闻门户最常见的模块：一个盒子、四个标签、每个标签下十条。考验的是 序号对齐、标题截断、右侧数字不换行——三条只要有一条没处理，长标题就会把布局撑破。

新闻· 今日热榜更多 ›
    难点做法
    序号右对齐、数字等宽font-family: 等宽字体 + text-align: right
    长标题不撑破父级 min-width: 0，标题 overflow:hidden + text-overflow:ellipsis + white-space:nowrap
    右侧数字被挤走网格第三列 auto，标题列 1fr
    前三名突出:nth-child(-n+3) 改颜色，不用手写类名
    这里用 Grid 而不是 Flex 的原因：三列的宽度关系是"固定序号 + 弹性标题 + 自适应数字"， grid-template-columns: 26px 1fr auto 一句话就表达清楚了； 用 Flex 要写三次 flex 值，而且中间那列还是得单独加 min-width: 0 才不溢出。

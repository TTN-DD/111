数组与对象方法

第 16 讲 16-1.html map / filter / reduce / sort

下面这份数据是同一份数组，七个按钮分别用不同的方法处理它。 重点不是记住语法，而是记住每个方法返回什么：map 改形状、filter 减数量、 reduce 塌缩成一个值、sort 原地改顺序。

一、原始数据

一个对象数组，四个字段：书名、作者、评分、价格。

二、挑一个方法看结果

每次点击都会打印"原数组有没有被改"——这条比结果本身更重要。

选一个方法。
方法返回什么会不会改原数组典型用途
map长度相同的新数组不会取字段、算派生值
filter长度 ≤ 原数组的新数组不会按条件筛
reduce任意类型的单个值不会求和、分组、去重
sort原数组（同一个引用）会排序，注意要传比较函数
find第一个匹配的元素或 undefined不会按 id 找一条
some / every布尔值不会存在性 / 全称判断
最常踩的坑：sort() 不传比较函数时，会把元素转成字符串按字典序排， 所以 [10, 9, 100].sort() 得到的是 [10, 100, 9]。 数字排序必须写 (a, b) => a - b。 另外 sort 是原地排序，想保留原数组要先 [...arr] 复制一份。

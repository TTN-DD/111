Flex 布局：六组对齐方式

第 7 讲 7.html Flexbox

用 Flex 只需要记住两件事：谁是容器（display:flex），谁是「主轴」（flex-direction）。 主轴方向定了，justify-content 就是主轴上的分布，align-items 就是垂直于主轴的对齐。

一、主轴方向

改 flex-direction，justify-content 的方向也跟着转 90°。

row（默认，横向）

flex-direction: row
123

row-reverse（反向）

flex-direction: row-reverse
123

column（纵向）

flex-direction: column
123

二、justify-content：主轴上的分布

六个取值一次看完，注意剩余空间是怎么被分配的。

flex-start

靠主轴起点，剩余空间全留末尾

center

整体居中，两侧空间相等
123

flex-end

靠主轴末端
123

space-between

两端贴边，中间均分 —— 做导航栏最常用
123

space-around

每个元素两侧空间相等，所以两端是中间的一半
123

space-evenly

所有间隙完全相等，包括两端

四、flex-grow：按比例分剩余空间

三个盒子的 flex 分别写 1 / 2 / 3，宽度比就是 1 : 2 : 3。

flex: 1 / 2 / 3

剩余空间按比例分配
123
.item-1 { flex: 1; }   /* flex-grow: 1 */
.item-2 { flex: 2; }
.item-3 { flex: 3; }

五、flex-wrap：装不下怎么办

三个盒子各占 30%，加上间距装不下 100%，换不换行是两种结果。

nowrap（默认）

挤在一行，盒子被压缩
123

wrap

装不下就换行
123
一句话判断该用哪组：一行排列、需要垂直居中、需要两端对齐 → Flex； 两维网格、行列都要对齐 → Grid。别拿 Flex 硬做网格， 也别为了一个垂直居中引入 Grid。

第 18 讲 18-8.html 1920×1080 等比缩放

大屏的标准做法：内部按 1920×1080 的绝对尺寸写死，外层按容器宽度整体缩放。 这样不管投到 1080p 的会议室屏幕上、还是塞进笔记本的半个窗口里，比例都不会乱。 数据用假数据每 2 秒刷新一次。

    等比缩放的三行代码

    const DASH_W = 1920, DASH_H = 1080;
const scale = viewport.clientWidth / DASH_W;

dash.style.transform = `scale(${scale})`;        // 内部尺寸不变，整体缩小
viewport.style.height = DASH_H * scale + "px";    // 外层高度跟着缩，避免留白

    关键是 transform-origin: top left。默认原点是中心，缩放后左上角会跑到容器外面去， 怎么调都对不齐。

    要点做法
    1920×1080 写死所有字号、间距用固定 px，不写 rem 也不写百分比——大屏只有一个分辨率基准
    整体缩放transform: scale()，比媒体查询一档档改尺寸稳得多
    折线图把数据点映射成 SVG polyline 的 points，不需要图表库
    环形图一个 conic-gradient 加一个挖空的内圆，两行 CSS
    数字跳动用等宽字体，否则每次刷新宽度变化会带着整行单元格一起抖
    大屏的两个真实约束：① 观众距离远，字号要大、对比度要高，正常网页那套 14px 灰字直接不可读； ② 投屏常见 1080p，但也可能是 4K 或超宽屏，所以"整体缩放"比"响应式重排"更靠谱—— 大屏不需要在手机上好看。

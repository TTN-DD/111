一百个盒子：逢 7 规则

第 15 讲 15-2.html 循环 + 取余 + 字符串查找

1 到 100 个格子：7 的倍数标绿、数字里含 7 的标蓝、两者都占的标深蓝，其余留白。 看着是排版练习，其实考三个 JS 基本功：% 取余、String.includes、 以及用 classList 控制状态。

普通 7 的倍数 含 7 两者都是

判定只有两行

for (let i = 1; i <= 100; i++) {
  const isMul = i % 7 === 0;              // 7 的倍数
  const has   = String(i).includes("7");  // 数字里含 7

  const cls = isMul && has ? "both" : isMul ? "mul" : has ? "has" : "";
  box.className = "bx " + cls;
}

注意判断顺序：必须先判"两者都是"，否则会被前一个条件拦下。 这也是嵌套三目运算符唯一值得用的场景——三个互斥状态，写出来比四个 if 短。

要点说明
100 个格子怎么排grid-template-columns: repeat(10, 1fr)，一行 10 个自动换行，不用算坐标
正方形格子aspect-ratio: 1/1，宽度由栅格决定，高度自动跟上
数字含 7先转字符串再 includes("7")，比对 100 取余简单得多
7 的倍数个数100 / 7 取整 = 14 个；含 7 的共 19 个；交集 2 个（7、70）
顺手验证一下答案：7 的倍数 14 个、含 7 的 19 个、两者都是的是 7 和 70 这 2 个。 勾选"只显示命中项"时，格子会重新排布（因为被隐藏的格子不再占据栅格位置）， 你会发现行数变少了——这是 display: none 和 visibility: hidden 的区别。

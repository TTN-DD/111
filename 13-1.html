图标的三种实现方案

第 13 讲 13-1.html 字体 / SVG / CSS

页面上一个 24px 的图标，可以是字体、可以是 SVG、也可以纯用 CSS 画出来。 三种方式在体积、着色、缩放、可访问性上各有取舍，选错的代价不是"不好看"，而是后期每改一次颜色都要重新导一次图。

方案一：字体图标

下面的符号本质是"看起来像图标的字符"，和文字同源，所以能直接改 color、font-size。

⌂✎⚙✉☰⌕ 
<!-- 实际项目里用 Font Awesome 这类字体库 -->
<!-- 优点：能当文字用；缺点：要加载字体文件，描边风格难调 -->

真正的字体图标（如 Font Awesome、iconfont）把每个图标做成字体里的一个字， 用 ::before 塞一个私有区字符来显示。好处是颜色、大小随文字继承， 坏处是多一个字体文件请求、且不同字体的字形风格很难统一。

方案二：内联 SVG

直接写在 HTML 里，用 currentColor 跟随文字颜色。

<svg viewBox="0 0 24 24" fill="none" stroke="currentColor">
  <path d="M3 10.5 12 3l9 7.5"/>
</svg>

方案三：纯 CSS 绘制

用伪元素 + 边框 + 变换画几何图形，一个字节的图片资源都不需要。

.i-plus::before { left: 10px; width: 2px; height: 22px; background: #2f6fed; }
.i-plus::after  { top: 10px; height: 2px; width: 22px; background: #2f6fed; }

只适合几何图形（加号、箭头、勾、汉堡菜单）。一旦要画"一本书"或"一个相机"， CSS 会膨胀成几十行而且难维护，那时候就该用 SVG 了。

维度字体图标内联 SVG纯 CSS
请求数1 个字体文件（可能 100KB+）0（写在 HTML 里）0
改颜色继承 color继承 color（currentColor）改 border/background
无限缩放是（矢量）是（矢量）是（几何计算）
多色图标不支持支持勉强
可访问性要加 aria-hidden可加 role + title需 aria-label
适合场景大量同风格图标首选，绝大多数情况简单几何符号
结论：默认用内联 SVG。只有在已经有成熟的字体图标体系（比如整个项目都在用 Font Awesome）时才用字体图标； CSS 图标只用来处理那些"画三条线就能解决"的符号，别拿它画复杂图形。

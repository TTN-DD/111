层叠样式表：三种引入方式

第 3 讲 3-1.html CSS 引入

同一个页面里可以同时存在三种写 CSS 的地方。它们不是"随便挑一种"，而是各有适用范围： 外链管全站，内嵌管单页，行内管特例。这一页把三种都写出来，看它们的实际效果和优先级。

一、写法对比

三段的样式分别来自三个不同位置，肉眼看起来差不多，来源完全不同。

外链

最推荐。一个 CSS 管所有页面，改一次全站生效，浏览器还能缓存。

<link rel="stylesheet"
      href="assets/demo-link.css">

内嵌

写在 head 里，只影响当前文档。适合页面独有的那几条规则。

<style>
  .from-embed { color: #8a3a0b; }
</style>

行内

直接写在标签上，优先级极高但无法复用，只用于调试或邮件模板。

<p style="color: #6b21a8">
  文字
</p>

二、三者同时命中同一个元素

下面这个方块同时被行内、id、类三条规则命中，看谁说了算。

我的颜色来自哪里？
行内 style → 1000 id → 100 class → 10 标签 → 1
规则选择器权重是否生效
行内style="background:#fff7e6"1000背景生效
id#target100颜色生效
类.target-class10被上面两条盖掉

所以最终结果：背景来自行内，文字颜色来自 id，类里的 background / color 都被覆盖了——但类里没被覆盖的 border-radius 依然生效。层叠是按属性逐个比较的，不是整条规则整体胜出。

三条结论： ① 优先级是四位数字比较（行内 / id / class / 标签），不是数字越大越"高级"； ② 同权重时，后写的覆盖先写的； ③ !important 能强行提权，但它会让后面的维护者失去判断依据， 只在覆盖第三方库时才用，自己的代码里不要写。

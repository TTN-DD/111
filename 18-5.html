矩阵坐标系：一周课时热力表

第 18 讲 18-5.html Grid 矩阵 + 深浅映射

五行（星期）× 六列（时段）的二维数据，用 Grid 摆成矩阵，用颜色深浅表示数值大小。 午休时段横跨三列合并成一格，最底下的滑块能联动高亮某一列——这是"表格 + 热力图"最常见的两种交互。

课时少 课时多 悬停格子看明细
把鼠标移到任意格子上。

合并单元格：Grid 的 span

"午休"横跨三列，只需要 grid-column: span 3，不用 table 的 colspan。

.matrix { display: grid; grid-template-columns: 56px repeat(5, 1fr); }
.cell.break { grid-column: span 3; grid-row: span 1; }

顺便一个表格做不到的事：每个格子都能单独做 transform 和 box-shadow， 悬停时轻轻抬起，视觉上就像"活的"。

要点做法
数值 → 颜色把数值归一化到 1–5 档，映射到 lv1…lv5 五个类，不做渐变以保持可读
行列标签第一列放星期，第一行放时段，用同一套 Grid 布局自然对齐
午休合并grid-column: span 3，斜纹背景表示"不排课"
行联动滑块改变时，给目标行以外的格子加 .dim（透明度 28%），并实时汇总该行总课时
深色底不用纯色第 4、5 档改成白字，保证对比度够（WCAG AA）
配色可读性：热力图最怕"看不出差别"。五个档位的亮度差要均匀， 而且第 4 档开始就得换白字——深蓝底配深灰字是典型的不可读组合，肉眼看着有字，实际对比度只有 2:1 左右。

纯 CSS 图标

第 13 讲 13-3.html 零资源 · 10 个图标

不加载字体、不写 SVG、不引图片，只用 ::before、::after、边框和 transform 画出几何图标。代价是每个图标都要手算位置，收益是零请求、零依赖， 而且改颜色就是在 CSS 里改一个值。

一、十个图标

移上去看动效——关闭和加号会转 90°，播放会放大。

二、三个关键技巧

会了这三个，大部分几何图标都能自己画。

① 折角：用 border 拼出"L"，再旋转

.ic-arrow::after {
  width: 9px; height: 9px;
  border-top: 2px solid #2c333d;
  border-right: 2px solid #2c333d;
  transform: rotate(45deg);   /* 边框拼的是 "⌐"，转 45° 就成了 ">" */
}

② 三角形：用透明边框

.ic-play::before {
  width: 0; height: 0;
  border-left: 14px solid #2c333d;      /* 实边：三角形的底 */
  border-top: 8px solid transparent;    /* 透明边：切出斜边 */
  border-bottom: 8px solid transparent;
}

③ 圆环：单边换个颜色 + 旋转

.ic-load::before {
  inset: 3px;
  border: 2px solid #dbe4f5;
  border-top-color: #2f6fed;   /* 只让上边有颜色 */
  border-radius: 50%;
  animation: ic-spin .9s linear infinite;
}
图标用了什么代码量
汉堡 / 加号 / 减号两条或三条背景色横竖条3 行
关闭同一根竖条旋转 ±45°3 行
箭头 / 勾 / 下拉两条边框 + rotate5 行
播放透明边框拼三角形4 行
更多一个圆点 + box-shadow 复制两个3 行
加载环圆角边框 + 单边着色 + 动画6 行
什么时候别用：图形一旦超出"直线 + 折角 + 圆"的范围（比如一本书、一个购物车、一个相机）， CSS 的代码量会指数膨胀，而且不同浏览器 1px 的差异会让形状歪掉。 这条界限大概是能用 3 个伪元素以内画出的，才值得用 CSS。
